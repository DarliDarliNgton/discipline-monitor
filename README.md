# Система мониторинга дисциплины на занятиях

Веб-приложение для автоматического обнаружения нарушений дисциплины с использованием компьютерного зрения и нейросетевых моделей.

## Возможности

- Детекция нарушений: сон, использование телефона, еда и напитки
- Поддержка трёх источников видео: веб-камера, видеофайл, URL/RTSP поток
- Журнал нарушений в реальном времени с временными метками
- Распознавание личности нарушителя (InsightFace)
- Запись видеосегментов при каждом нарушении
- Скачивание отчёта в форматах TXT и CSV
- Полный журнал ошибок прямо в интерфейсе

## Технологии

- Python 3.10+
- Streamlit — веб-интерфейс
- YOLOv11 (Ultralytics) — детекция объектов
- OpenCV — обработка видео
- InsightFace — распознавание лиц
- streamlit-webrtc — захват веб-камеры

## Установка и запуск

### Требования
- Python 3.10 или выше
- Веб-камера (для режима веб-камеры)

### Шаг 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 2. Обучение модели

Скачайте датасет с [Roboflow Universe](https://universe.roboflow.com/) (классы: sleeping, phone_usage, bottle, food), распакуйте в `datasets/` и запустите:

```bash
python train_model.py
```

Или поместите готовый файл `best.pt` напрямую в папку `models/`.

### Шаг 3. Запуск приложения

```bash
streamlit run app.py
```

Откройте в браузере: http://localhost:8501

```
│   └── report_generator.py   # Генерация отчётов

│   └── reports/              # Сохранённые отчёты
└── logs/
    └── app.log               # Журнал ошибок и событий
```

## Просмотр ошибок

Все ошибки отображаются в блоке **"Журнал ошибок"** прямо в интерфейсе приложения, а также записываются в файл `logs/app.log`.
